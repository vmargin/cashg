# .claude/agents/

> Managed by Sauron.

## Purpose

Project subagents with their own system prompt, tools, and model.

## How to add a file

Create `.claude/agents/<agent-name>.md`.

## File format

Markdown with YAML frontmatter `name`, `description`, optional `tools` and `model`; body is the system prompt.
