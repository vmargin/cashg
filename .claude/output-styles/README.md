# .claude/output-styles/

> Managed by Sauron.

## Purpose

Custom output styles that change how Claude responds.

## How to add a file

Create `.claude/output-styles/<style-name>.md`.

## File format

Markdown with YAML frontmatter `name` and `description`; body is the style prompt.
